# Burger Restaurant

Bienvenue sur le projet **Burger Restaurant** ! 🍔 Ce site web est conçu pour être un restaurant en ligne où les utilisateurs peuvent consulter le menu et passer commande. Le projet inclut plusieurs pages HTML, du CSS pour la mise en forme, et du JavaScript pour rendre le site interactif.

---

## Structure du projet

Le projet est organisé de la manière suivante :

- **index.html** : Page d'accueil avec introduction et présentation du restaurant.
- **about.html** : Page de présentation du restaurant, de son histoire et de sa mission.
- **contact.html** : Formulaire de contact pour permettre aux clients de poser des questions ou de faire des commentaires.
- **blogs.html** : Section des blogs avec des articles sur les burgers, des recettes, et des nouveautés.
- **menu.html** : Page détaillant le menu avec les différents types de burgers, boissons et options.
- **products.html** : Détail des produits offerts, y compris les images et les descriptions.
- **review.html** : Section avec les avis des clients sur les burgers et le service.
  
---

## Fonctionnalités

- **Menu interactif** : Permet aux utilisateurs de consulter le menu et de passer commande.
- **Design réactif** : Le site s'adapte aux différentes tailles d'écrans (mobile, tablette, bureau).
- **Formulaire de contact** : Permet aux clients de poser des questions directement depuis le site.
- **Avis clients** : Affiche des commentaires d'utilisateurs sur leur expérience au restaurant.

---

## Technologies utilisées

- **HTML** : Pour la structure de base du site.
- **CSS** : Pour la mise en forme et le style du site.
- **JavaScript** : Pour ajouter des fonctionnalités interactives comme des notifications ou des formulaires.

1. Clonez le dépôt :

    ```bash
    git clone https://github.com/tbasdev57/burger-restaurant.git
    ```
